## Jump to Definition (Very Helpful Tip)

If you ever have a doubt about **any class, function, method, variable, or import**, you can instantly jump to its definition:

- **Windows / Linux:** `Ctrl + Click`  
- **Mac:** `Cmd + Click`  

This opens the **actual source code or declaration**, helping you understand:
- What it does  
- How it works  
- Where it is defined  

> ⚠️ Note: This works for symbols (classes, functions, variables, imports),  
> but **not** for language keywords like `int`, `if`, `for`, `while`, etc.
