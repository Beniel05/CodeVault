## 🏷️ Naming Convention

Files follow a simple **sequential naming pattern** to represent the learning order:

A00, A01, A02, A03, ...

Each number represents the **next step in progression**, not the difficulty level.

### Example:
- A00_CreatingAnArray
- A01_ArrayInputUsingScanner
> And so on!
